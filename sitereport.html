Reflection of Module Experience

Throughout this module, I developed my understanding of HTML, CSS and the basics of web development. At the start, I found it difficult to understand how different parts of a website work together, especially layout and styling. However, after completing weekly exercises and building this assignment, my confidence improved significantly.

One of the biggest challenges I faced was debugging my code. Small mistakes such as missing tags or incorrect CSS would break parts of my website, which was frustrating. Over time, I learned how to fix these issues using validators and browser tools. This helped me improve my problem-solving skills and understand how websites are built more clearly.

Design Decisions

I chose a dark theme with blue highlights to create a modern and clean design. The blue colour is used for headings and important elements so they stand out. I used the Segoe UI font because it is simple, readable and works well across different devices.

My design was influenced by modern portfolio websites such as Dribbble and Awwwards. I also used the grid layout exercises from class as a base for structuring my pages.

I used CSS Grid and Flexbox to organise content and ensure the layout is responsive. The navigation bar is consistent across all pages, making it easy to move through the site.

Technical Development

The website was built using HTML5 and CSS3. I used semantic elements such as <nav>, <main> and <section> to structure the content correctly. A single CSS file (main.css) was used to maintain consistency across all pages.

Media queries were added to make the website responsive, and a hamburger menu was implemented for mobile devices. This ensures that the navigation works properly on smaller screens.
